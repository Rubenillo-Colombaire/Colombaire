# COLOMBOMETEO V26.1 — Corrección de lluvia

Laboratorio independiente para corregir los intervalos de precipitación del modelo ECMWF IFS.

Objetivo: representar correctamente la lluvia acumulada en cada intervalo de 3 horas.

Intervalos:
- +15 a +18 horas
- +18 a +21 horas
- +21 a +24 horas

Estado: experimental, pendiente de validación con datos reales.

La versión V26-REJILLA-LAB permanece intacta.
